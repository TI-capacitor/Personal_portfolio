About

I'm a computer engineering junior at the Inter American University of Puerto Rico Bayamón. Most of what I build is hardware: PCBs in KiCad, firmware for ESP32 and Arduino boards, and robots that need both. I also write web software when a project calls for it, like the booking system that runs my tutoring business.

Last season I led the programming team for NASA Lunabotics. I run Dan Tutoring and hold an FAA Part 107 remote pilot certificate. I'm looking for roles where I can work on both sides of the hardware and software line.
